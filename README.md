# CRM Eltech Química

Sistema de gestão comercial e marketing da Eltech Química, acessado pelo navegador.

- **Tecnologia:** Next.js 15 + Supabase (banco, login e permissões) + Tailwind CSS
- **Banco de dados:** projeto Supabase `fifdlndfyhrbtmsdaypq`

## Rodar no computador (desenvolvimento)

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abra http://localhost:3000.

## Etapas do projeto

1. ✅ Estrutura, layout e login
2. Banco de dados e permissões por perfil
3. Importação da planilha DADOS_GERAIS_CRM
4. Telas com dados reais (dashboard por perfil, contatos, pipeline Kanban, preços, comissões)
5. Convite dos usuários e publicação
